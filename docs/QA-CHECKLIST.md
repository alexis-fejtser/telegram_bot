# QA-чеклист: админ-панель и бот

Документ для ручного прогона функциональности на реальном стенде.
Автотесты (`npm test`) покрывают API-часть; пункты ниже дополняют их
проверками в браузере и в самом Telegram-боте.

## Подготовка стенда

1. Запущен MySQL (локально, порт 3306).
2. Заполнены сцены: `node scripts/seedScenes.js` (если база пустая).
3. Применена миграция порядка сцен (однократно, идемпотентно):
   `npm run migrate:scene-order`.
4. Запущен бот и API: `npm start` (в логе — «Бот запущен и готов к работе»).
5. Собран актуальный UI: `cd client && npm run build`.
6. Админка открыта по адресу `http://localhost:3000` (порт из `PORT`), вход по паролю `ADMIN_SECRET` из `.env`.
7. Тестовый Telegram-аккаунт для проверок бота.

## 2. Редактор сцен

### 2.1 Сцены

| № | Шаги | Ожидаемый результат |
|---|------|---------------------|
| 2.1.1 | «+ Сцена» → ввести ID и название | Сцена появляется в списке, выбрана; создаётся с одним шагом и сообщением; в боте `/start` — новая кнопка |
| 2.1.1a | Попробовать создать сцену с существующим ID | Алерт с ошибкой, дубликат не создаётся |
| 2.1.2 | Изменить название, описание, снять/поставить «Активна», отредактировать шаги → «Сохранить изменения в БД» | Алерт «Сцена успешно сохранена»; после F5 изменения на месте; в боте текст/меню соответствуют правкам |
| 2.1.3 | Нажать корзину у сцены → подтвердить | Сцена исчезает из списка; в боте кнопки сцены больше нет; последнюю сцену удалить нельзя (кнопка скрыта) |
| 2.1.4 | Перетащить сцену за ручку-грип вверх/вниз | Порядок в списке меняется и сохраняется сразу (без кнопки «Сохранить»); после F5 порядок тот же; в боте `/start` нумерация «Кнопка N» и список описаний соответствуют новому порядку |

### 2.2 Шаги

| № | Шаги | Ожидаемый результат |
|---|------|---------------------|
| 2.2.1 | «Добавить шаг» | Новый шаг в конце списка, «Шаг №N»; после сохранения и F5 шаг на месте |
| 2.2.2 | Корзина у шага | Шаг удаляется; нумерация «Шаг №…» пересчитывается без пропусков; после сохранения в БД `stepIndex` идут подряд (0, 1, 2…) |
| 2.2.3 | Перетащить шаг за грип (опционально, без сохранения) | Шаги меняются местами в UI; до сохранения изменения не влияют на бота; после сохранения — бот показывает шаги в новом порядке |

### 2.3 Сообщения

| № | Шаги | Ожидаемый результат |
|---|------|---------------------|
| 2.3.1 | «+ Сообщение» внутри шага | Новое текстовое сообщение в конце шага; можно сменить тип (текст/фото/видео/кружок) |
| 2.3.2 | Крестик у сообщения | Сообщение удаляется; остальные не смещаются |
| 2.3.3 | Изменить текст, тип, файл/assetKey, caption, инлайн-кнопки → сохранить → открыть сцену в боте | В боте отображается отредактированный контент; кнопки с action `next`, `lead:question`, `lead:consultation` работают |
| 2.3.4 | Перетащить сообщение за грип внутри шага → сохранить | Порядок сообщений сохранён после F5; в боте сообщения приходят в новом порядке (с учётом задержки из настроек) |
| 2.3.5 | Убрать все сообщения из шага → сохранить | Шаг пустой; бот переходит к следующему шагу/завершает сцену без ошибок (проверить лог) |
| 2.3.6 | У сообщения, которое не является последним в шаге | Блок инлайн-кнопок недоступен — отображается подсказка «Инлайн-кнопки доступны только у последнего сообщения в шаге»; даже если кнопки были добавлены ранее, после сохранения они срезаются (проверяется и сервером) |
| 2.3.7 | Добавить кнопки последнему сообщению → перетащить его выше последнего → сохранить | Кнопки этого сообщения в БД становятся пустыми; в боте кнопки приходят только у последнего сообщения шага |

### 2.4 Медиатека и прикрепление файлов

| № | Шаги | Ожидаемый результат |
|---|------|---------------------|
| 2.4.1 | В сообщении типа «Фото»/«Видео»/«Кружок» нажать «Медиатека» | Открывается модальное окно со списком загруженных файлов; есть фильтры «Все/Фото/Видео/Кружки», превью файлов и кнопка «Загрузить с компьютера» |
| 2.4.2 | Выбрать файл в медиатеке | Модалка закрывается; в сообщении появляется маленькое превью (фото) или мини-постер (видео, кружок — круглый) и имя assetKey; после сохранения бот отправляет этот файл |
| 2.4.3 | «С компьютера» → выбрать файл | Файл загружается в `uploads/` и появляется в медиатеке; сообщение сразу привязывается к новому assetKey (превью обновляется) |
| 2.4.4 | У сообщения «Кружок» загрузить видеофайл | Тип записи в медиатеке — `videoNote`; превью круглое; в боте уходит кружок |
| 2.4.5 | «Ввести ключ вручную» → ввести assetKey или путь к файлу → сохранить | Значение сохраняется как раньше (assetKey для ключа, file для пути); бот отправляет файл |
| 2.4.6 | Вернуться к сообщению с уже прикреплённым фото (после F5) | Отображается маленькое превью прикреплённого фото/постера; для отсутствующего в медиатеке пути — серая заглушка с иконкой типа |
| 2.4.7 | В медиатеке навести на файл → корзина → подтвердить | Запись и файл в `uploads/` удаляются; сообщения, ссылающиеся на этот assetKey, показывают заглушку |

## 4. Чат с вопросами пользователей

| № | Шаги | Ожидаемый результат |
|---|------|---------------------|
| 4.1 | Отправить боту вопрос от тестового аккаунта → открыть «Мессенджер & Вопросы» | Вопрос в списке со статусом «Ожидает», видно ID и время |
| 4.2 | Выбрать вопрос; проверить шапку чата | Отображается имя и `@username` пользователя, его Telegram ID и дата |

## 5. Страница настроек

| № | Шаги | Ожидаемый результат |
|---|------|---------------------|
| 5.1 | Открыть «Настройки» | Показаны: маскированный токен (`123456789:••••••••XXXX`), MANAGER_ID, три таймера, тексты лидов, форма смены пароля |
| 5.2 | Изменить MANAGER_ID → «Сохранить» | «Настройки сохранены»; новому менеджеру приходит уведомление о следующем вопросе; пустое поле = MANAGER_ID из `.env` |

| 5.4 | Изменить таймеры (например, задержку 1000 мс) → сохранить → прогнать сцену с ≥2 сообщениями в шаге | Второе сообщение приходит примерно через 1 сек; при некорректном значении (−5, > 86400000) — ошибка |
| 5.5 | Ввести новый токен бота (без перезапуска) | Жёлтый баннер «Токен изменён, применится после перезапуска»; после `npm start` бот работает с новым токеном |
| 5.6 | Вставить невалидный токен | Ошибка «Некорректный формат токена бота» |
| 5.7 | Изменить текст `lead:consultation` → сохранить → в боте нажать кнопку заявки | Пользователю приходит новый текст; HTML-разметка (`<a href="tel:…">`) корректно рендерится |
| 5.8 | Изменить `questionPrompt` → нажать «❓ Задать вопрос» в боте | Приходит новый текст приглашения |
| 5.9 | Изменить `questionThanks`/`questionError`/`questionNotText` → отправить вопрос текстом / не-текстом (стикер) | Приходят соответствующие тексты из настроек |
| 5.10 | Изменить уведомление менеджеру (шаблон с `{name}`, `{username}`, `{telegramId}`, `{question}`) → отправить вопрос | Уведомление приходит с подставленными данными; HTML-теги работают; символы `<`, `>` в тексте вопроса экранируются |
| 5.11 | Смена пароля: неверный текущий | Ошибка «Неверный текущий пароль» |
| 5.12 | Смена пароля: новый короче 6 символов | Ошибка «Новый пароль должен быть не короче 6 символов» |
| 5.13 | Смена пароля: пароли не совпадают | Ошибка «Пароли не совпадают» |
| 5.14 | Успешно сменить пароль → выйти → войти новым; попробовать старый (ADMIN_SECRET) | Вход работает только с новым паролем; старый отклоняется с 401 |
| 5.15 | Перезапустить бота после смены пароля и токена | Вход возможен по новому паролю (хэш сохранён в БД), токен применён |

## Регрессионные проверки бота (после изменений в настройках и сценах)

| № | Шаги | Ожидаемый результат |
|---|------|---------------------|
| R.1 | `/start` новым пользователем | Главное меню: приветствие, список описаний сцен по порядку, кнопки «✅ Кнопка N» по порядку из админки |
| R.2 | Диплинк `t.me/<bot>?start=first_scene` (и `first_scene_step_1`, если настроено) | Нужная сцена открывается с нужного шага |
| R.3 | `/menu`, `/exit`, «🏠 Главное меню» внутри сцены | Возврат в главное меню, таймеры шага отменяются |
| R.4 | Заблокировать бота → разблокировать из Telegram | В «Пользователях» статус меняется на «Заблокирован» → «Активен»; в истории события «Заблокировал/Разблокировал бота» |
| R.5 | Автопереход шага по таймауту (STEP_TIMEOUT) | По истечении таймаута бот переходит к следующему шагу/завершает сцену |
| R.6 | «Кружок» (videoNote) и медиа с невалидным file_id | Бот подставляет локальный файл, ошибка не ломает сцену (смотреть лог) |
